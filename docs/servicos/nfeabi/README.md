# NF-e ABI

Esta seção reúne os serviços de NF-e ABI disponíveis no UniNFe por integração de arquivos.

Os serviços disponíveis são executados somente no ambiente de homologação. O UniNFe não transmite NF-e ABI para produção e não disponibiliza, por esta integração, consulta de protocolo ou eventos.
